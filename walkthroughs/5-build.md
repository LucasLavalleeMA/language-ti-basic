# Optional: build from source

Only needed if there is no prebuilt binary for your platform or you want a custom build. See the extension's `docs/building-cemu.md` for:

- building native CEmu with CMake, vcpkg or qmake
- producing the WebAssembly files (`cemu.js`, `cemu.wasm`) for the embedded sidebar calculator

After building native CEmu, run **TI-BASIC: Locate CEmu Executable** and select it.
