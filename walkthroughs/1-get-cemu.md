# Get CEmu

CEmu is a free TI-84 Plus CE / TI-83 Premium CE emulator for Windows, macOS and Linux. **You do not need to build it.** Prebuilt binaries are published on the CEmu releases page:

https://github.com/CE-Programming/CEmu/releases

Pick a build for your OS:

| OS | Download |
| --- | --- |
| Windows | the **Qt6 MSVC 64-bit** build (recommended) |
| macOS | the **Qt6** build for Apple Silicon (arm) or Intel |
| Linux | the **Qt6** 64-bit build (needs glibc 2.28+); a Qt5 build also exists |

The page has a stable release and an auto-updating **nightly**. The stable release is quite old; the nightly is the recommended choice for current features.

Unzip or install it anywhere you like, run it once, and move on to the next step. If it is in a standard location the extension finds it automatically; otherwise use **Locate CEmu** in step 3.

> CEmu is a third-party project, not a TI product. It is licensed GPLv3.
